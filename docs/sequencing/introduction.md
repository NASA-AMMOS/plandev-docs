# Sequencing

The SeqDev editor provides a sequence development environment within PlanDev. Author sequences and adapt SeqDev to fit your needs:

- Start using the SeqDev editor out of the box with the [SeqN](/plandev-docs/sequencing/seqn) authoring language and the [SeqJSON](https://github.com/NASA-AMMOS/seq-json-schema) interchange format.
- Leverage the [editor adaptation](/plandev-docs/sequencing/adaptation) to configure additional languages or implement support for your own.
- Use [SeqDev Actions](/plandev-docs/sequencing/actions) for external integrations.
