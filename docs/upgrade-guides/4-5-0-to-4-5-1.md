# 4.5.0 to 4.5.1

PlanDev **4.5.1** is a security update to mitigate a recently-discovered vulnerability in OpenJDK, a core dependency of PlanDev - see [this security advisory for details](https://github.com/NASA-AMMOS/plandev/security/advisories/GHSA-9vfh-469q-v98h).

We recommend that users running **PlanDev 4.5.0** upgrade to **4.5.1** OR perform the [mitigation steps outlined in the advisory](https://github.com/NASA-AMMOS/plandev/security/advisories/GHSA-9vfh-469q-v98h) to mitigate this vulnerability.

No migrations or additional steps are necessary for this upgrade.
